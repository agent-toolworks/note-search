# /pay returns 504

1. Check the card processor status page.
2. Check `paygw_pool_in_use` on the payment-gateway dashboard. Above 90%: look
   for a retry storm from orders-api.
3. If retries are the cause, set `ORDERS_PAY_RETRIES=0` for 15 minutes.
4. Do not raise `PAYGW_POOL_SIZE` above 60: the processor limits connections.
